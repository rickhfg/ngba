# ngba
Lightweight, high-performance Game Boy Advance emulator written in modern C++ with native execution.

NGBA is a lightweight, standalone Game Boy Advance emulator built from scratch in C++14. It was designed for performance and simplicity.

It features an ARM7TDMI core with native translation fallback, cycle-stepped timers and DMA, a complete 2D PPU pipeline, and a responsive Win32 GUI with 12 save slots and frame pacing.
